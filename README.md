# Craft

A minimalistic (and opinionated) approach to building with AI agents, without losing control.

The plugin lives in [`plugin/`](plugin/), and [its README](plugin/README.md) says what it does and how to install it. That folder is all an install copies.

The rest of this repository is how craft is built and checked: [`evals/`](evals/) holds the eval suite, [`docs/craft/`](docs/craft/) the works craft was built with, and [`CHANGELOG.md`](CHANGELOG.md) what each version changed.
