# How it looks

If the human already has the look (a Figma link, screenshots, an existing screen), record it and draw nothing: the link as is, screenshots copied into `docs/craft/<slug>/look/`.

Otherwise load the `artifact-design` skill with `Skill` and draw each screen as one self-contained HTML file, `docs/craft/<slug>/look/<screen>.html`. 

When the look is open, draw 2 to 4 directions, each named for the axis it explores.

Link each screen with one line: its name and the file or url.

Write with `Write`, look at it once, and move on.
