# How it looks

If the human already has the look (a Figma link, screenshots, an existing screen), record it and draw nothing: the link as is, screenshots copied into `look/` in the work's folder.

Otherwise load the `artifact-design` skill with `Skill` and draw each screen as one self-contained HTML file, `look/<screen>.html` in the work's folder. 

When the look is open, draw 2 to 4 directions, each named for the axis it explores.

Embed each screenshot with `![<screen>](look/<screen>.png)`, and link each HTML file with `[<screen>](look/<screen>.html)` and each url with `[<screen>](<url>)`, one line per screen.

Write with `Write`, look at it once, and move on.
