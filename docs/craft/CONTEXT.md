# Craft

A Claude Code plugin: an opinionated methodology for building software with AI agents, one living board per feature. Used by whoever installs it from the marketplace; developed here with `claude --plugin-dir`. Built with skills and agents in markdown, plus a zero-dependency Node board server (`lib/`).

## Read for

- The words we use, and the ones we avoid: `glossary.md`
- Gotchas and conventions a model could not infer from the code: `conventions.md`
- Cross-cutting decisions, one line each: `decisions.md`

A file that does not exist yet has nothing in it. Craft creates each one the first time something passes.
