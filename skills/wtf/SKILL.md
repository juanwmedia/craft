---
name: wtf
description: Say the last answer again so it lands, when the human is lost or a fragment made no sense.
argument-hint: "[the fragment that did not land]"
disable-model-invocation: false
---

Wtf answers what the last answer meant, said again so it lands. It never advances the work: it reads only what the explanation needs, and changes nothing.

Its input is `$ARGUMENTS`, the fragment that did not land, or the last answer when there is none. Write in the language the human speaks.

Name in one line what the answer assumed the human knew.

Say it again: what it means for them first, how it works after. Use only words they have used, and define in one line any term that cannot be avoided.

Then say what is done, what is pending and what waits on the human, and the one next action, or that there is none.

The failure was the answer's: never defend it, and add no decision or option it did not have. Something new found while explaining is named as new, and it stops there.
